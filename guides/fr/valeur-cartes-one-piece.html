1. Lire une carte One Piece

  • Le code, en bas à droite (par exemple OP05-119) : l'extension puis le numéro. Les extensions principales s'appellent OP-01, OP-02, etc. ; il existe aussi des decks de démarrage (ST) et des extra boosters (EB).
  • La rareté, à côté du code : C (commune), UC (peu commune), R (rare), SR (super rare), SEC (secrète), L (Leader).
  • La langue : japonais, anglais, et d'autres langues selon les régions.

2. Les cartes qui valent cher

  • Les versions alternatives (parallèles) : même carte, illustration différente, plus rares.
  • Les cartes « manga », illustrées avec des cases du manga : parmi les plus recherchées.
  • Les SP et les cartes spéciales glissées dans certaines extensions.
  • Les SEC et les Leaders en version alternative.
  • Les personnages populaires : Luffy, Shanks, Zoro, Nami, Yamato…

3. Ce qui fait bouger les prix

Le One Piece Card Game se joue beaucoup en tournoi : une carte forte dans les decks du moment peut monter vite, puis redescendre quand le jeu évolue. Les cartes de collection (manga, alternatives) dépendent plus de la popularité du personnage et de l'illustration.

4. Vérifier avant d'acheter

Comme pour Pokémon, compare avec l'image officielle, regarde les ventes réelles plutôt que les annonces, et méfie-toi des cartes « manga » à petit prix : voir les cartes One Piece sur eBay.

Questions fréquentes

Japonais ou anglais ?

Les cartes japonaises sortent en premier et sont très recherchées par les collectionneurs ; les cartes anglaises sont souvent plus chères pour les mêmes raretés. Compare toujours la même langue.

Les cartes DON!! ont-elles de la valeur ?

Les DON!! classiques valent peu, mais certaines DON!! spéciales ou promotionnelles sont recherchées.
